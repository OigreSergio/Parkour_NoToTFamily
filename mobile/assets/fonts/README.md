# Font

**Quicksand** (Andrew Paglinawan & the Quicksand Project Authors), tondo e
amichevole: è il carattere dell'app, scelto perché il ricamo della mappa e i
suoi spilli chiedono una scrittura morbida, non l'interfaccia di un ufficio.

Pesi inclusi: 400 (testo), 600 (titoli e pulsanti), 700 (titoloni).
